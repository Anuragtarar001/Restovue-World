# Public-domain portrait fixture

`public_domain_portrait.jpg` is the official portrait of U.S. President Barack Obama
taken on December 6, 2012, by White House photographer Pete Souza. This fixture
matches the original file published by Wikimedia Commons. Source:
https://commons.wikimedia.org/wiki/File:President_Barack_Obama.jpg

Wikimedia Commons marks the file as public domain in the United States (PD-USGov).
The original file retains its White House usage notice in EXIF metadata. The
fixture is used only in Android instrumentation tests.
