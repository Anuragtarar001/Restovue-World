Privacy Policy — Restovue : Photo Editor

Effective draft date: 6 November 2026

Restovue : Photo Editor is developed by NextGen TechEdge Solutions. Restovue uses Android's system Photo Picker for user-selected images and the Storage Access Framework for user-selected output locations. Selected photos are processed locally and are not silently overwritten.

Collection and sharing

The audited app contains no analytics, advertising, telemetry, accounts, remote configuration, crash-upload service, cloud image processing or network permission. It does not collect or share personal data through an application-operated server.

The developer link opens an external browser. Browser and website behavior is governed separately; Restovue does not transmit photos to that website.

Local data and files

Adjustment presets and imported LUT references may be stored in app-private storage. Exports are written only to locations selected by the user. Where offered, users choose whether supported metadata is preserved.

Retention and deletion

There is no server-side retention. Delete exports using the selected storage provider, delete presets in Restovue, or clear app-private data by uninstalling or using Android's clear-storage control.

Contact

For support and privacy enquiries, visit NextGen TechEdge Solutions.
