# Privacy Policy — Restovue : Photo Editor

Effective draft date: 6 November 2026

Restovue : Photo Editor is developed by NextGen TechEdge Solutions. This policy describes the behavior of the release-candidate Android application reviewed with this document.

## Photo and file access

Restovue uses Android's system Photo Picker for user-selected images and the Storage Access Framework for user-selected output locations. It does not request broad storage access. Selected photos are processed locally on the device and are not silently overwritten.

## Data collection and sharing

The audited application contains no analytics, advertising, telemetry, account system, remote configuration, crash-upload service, cloud image processing, or network permission. The application does not collect or share personal data through an application-operated server.

Tapping the developer website opens the device's external browser. Browser behavior and the destination website are governed separately; Restovue itself does not load the website or transmit photos.

## Local data

User-created adjustment presets and imported LUT references may be stored in application-private storage. Exported images are stored only at locations selected by the user. Android or the selected document provider may retain recent-file information independently of Restovue.

## Metadata

Where offered, users can choose whether supported photo metadata is preserved or removed. Export orientation is normalized. Users should review exported files before sharing them.

## Retention and deletion

Restovue has no server-side retention. Users can delete exported files through their chosen storage provider, delete presets in the app, and clear all app-private data by uninstalling the app or using Android's clear-storage control.

## Children, advertising and tracking

Restovue is a general-purpose photo utility. It contains no targeted advertising or tracking SDK. The Play Console target-audience declaration remains an owner decision and must match the final store listing.

## Changes and contact

This policy must be reviewed whenever application data flows or dependencies change. For support and privacy enquiries, visit https://www.nextgentechedge.com/.
