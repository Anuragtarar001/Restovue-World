# Restovue 0.9.0-rc1 release candidate

This directory contains owner-testing material and Google Play preparation documents. It does not contain signing keys, passwords, private photographs, or a claim that the application has been published.

- `testing/`: manual acceptance plan
- `play-store/`: approved store art and truthful listing copy
- `privacy/`: publication-ready privacy-policy drafts
- `compliance/`: Data Safety and Play Console owner checklist
- `reports/`: feature, security, dependency, performance, and build findings
- `artifacts/`: generated APK/AAB copies and signing notes

The release bundle is unsigned unless all four `RESTOVUE_UPLOAD_*` environment variables described in `artifacts/SIGNING.md` are supplied by the owner.
